# Glitch Brushes

Glitch Brushes — локальная мастерская изображений проекта **Parkour Kotenok**. PNG, JPEG и WebP обрабатываются прямо в браузере и никуда не отправляются.

## Что есть в редакторе

- **Effect** — структурные RGBA-эффекты и glitch-кисти. В Simple остаются главные настройки, Advanced открывает точные параметры. Превью эффектов — заранее подготовленные статичные рендеры на одном пейзажном фоне, поэтому они не зависят от текущего документа и не нагружают интерфейс.
- **Retouch** — Smudge, Photoshop-like Finger, Blur, Sharpen, Restore и Eraser. Тяжёлая обработка выполняется локально после мазка, а во время движения используется облегчённый непрерывный след.
- **Mosh Lab** — последовательные цепочки эффектов с областями, предпросмотром, отменой и одним атомарным применением.
- **Image Brush** — изображение как штамп: пресеты, мутация, Stamp FX, несколько режимов раскладки, upright/follow-stroke ориентация и библиотека кистей.
- **Layers** — каждая добавленная фотография является отдельным скрываемым raster-слоем над белым Background. Слои перетаскиваются за grip без копирования pixel-буферов; Background можно открепить и превратить в обычный редактируемый слой. Effect, MOSH, Retouch и Image Brush изменяют выбранный слой напрямую, а `All Layers` переключает источник семплирования.
- **Simple / Advanced** — быстрый режим без стены ползунков и полный режим для тонкой настройки.
- **Compact browsers** — Effect, Mosh Add Effect и Image Brush Style используют общий компактный браузер иконок с клавиатурной навигацией, подсказками и закреплённым статичным preview выбранного эффекта.
- **Controls / Layers splitter** — высота панелей регулируется мышью или клавиатурой, сохраняется локально и автоматически ограничивается при изменении окна.

## NEW / Experimental

Экспериментальная пачка включает Effect Brushes **Mirror Fold**, **Raster Loom**, **Contour Crawl**, **JPEG Resample** и Image Brush FX **Pixel Embroidery**, **Xerox Decay**, **JPEG Resample**. Они помечены `NEW`, не входят в старые пресеты и random pools и активируются только явным выбором пользователя.

**JPEG Resample** использует единое детерминированное ядро настоящего JPEG encode/decode для Effect, Mosh и Image Brush. Кодек `jpeg-js 0.4.4` (BSD-3-Clause, без зависимостей, unpacked size 76 029 bytes) загружается только в Worker bundles; участок ограничен длинной стороной 2048 px и максимум четырьмя проходами. Alpha сохраняется отдельно и восстанавливается byte-exact.

Общие JPEG presets включают **High / Medium / Low / Melt**. 28 px — единый нижний предел codec resolution: меньшие старые значения автоматически нормализуются до него, чтобы изображение не распадалось в крупную мозаику. Melt сохраняет сильные quality 1, четыре прохода, RGB noise и chroma bleed, но использует smooth upscale; четырёхпроходный лимит не повышается.

Старые **HEX**, **File Corruption**, верхний пиксельный индикатор и кнопки Continuous / Stroke Commit / Preview удалены из рабочего интерфейса.

## Image Brush

- При первом запуске доступно одно демо-изображение астронавта; пользовательские кисти сохраняются локально в IndexedDB между сессиями.
- Essential Controls расположены выше Style и не перезаписываются при смене glitch-пресета.
- Progressive Decay сохраняет один и тот же структурный seed на всей линии и плавно меняет только силу повреждения; кривые и Decay Speed больше не сваливают основное разрушение в последние штампы.
- В Evolution доступен независимый `Fade along stroke`: Start/End Opacity и отдельная кривая постепенно снижают прозрачность вдоль мазка. Пока fade включён, общий Essential `Opacity` заблокирован и интерфейс явно показывает причину.
- Live Stroke Preview считается в Worker и показывает пять крупных штампов с увеличенным интервалом. Демонстрационный масштаб `2.25×` помогает рассмотреть мелкие FX; настоящий мазок на canvas использует точные `Size` и `Spacing`.
- Превью использует тот же layout/spacing/mutation pipeline, что и мазок, а интерактивный canvas ограничивает работу временным бюджетом кадра и кэширует варианты.
- Загруженные изображения декодируются и подготавливаются вне главного UI-потока; Optimize Stamp Image создаёт уменьшенную рабочую копию, сохраняя оригинал.

## Документ и слои

- `Add image` и drag-and-drop больше не заменяют документ: файл декодируется в Worker, при необходимости уменьшается до текущего холста, центрируется и добавляется сверху отдельным `Image`-слоем.
- Фотографии хранятся как raster-источники, а прямые изменения выбранного слоя — только в затронутых 256×256 sparse tiles. History использует copy-on-write: неизменённые raster/tile-буферы разделяются между снимками, а при мазке копируется только затронутый тайл.
- Пока Background не откреплён, скрытие всех `Image`-слоёв показывает белый холст. Reset очищает прямые изменения, но сохраняет сами добавленные фотографии.
- Кнопка Transform двигает слой и масштабирует его за угловые handles. Пропорции сохраняются по умолчанию; удержание `Shift` включает свободное изменение ширины и высоты. Во время drag используется только CSS/GPU preview, а bilinear resize выполняется один раз в Worker после Apply и создаёт одну History action.
- Слои можно переставлять drag-and-drop; пиксели при этом не пересчитываются до drop. Unlock у Background атомарно продвигает белый холст в обычный нижний raster-слой, поэтому действие отменяется через History.
- PSD открывается через `Add image` или drag-and-drop и экспортируется из обычного Export как `Photoshop PSD (layers)`. Кодек `ag-psd 30.2.0` работает только в отдельном Worker и сохраняет raster-слои, порядок, положение, visibility, opacity и поддерживаемые blend modes. Группы разворачиваются в плоский список, а text/vector/smart-object семантика импортируется только как доступный raster preview; PSB и 16-bit документы не поддерживаются.
- Project v3 сохраняет типы слоёв и raster-источники; старые проекты со sparse-слоями мигрируют поверх импортированного изображения.

### Известные ограничения слоя редактирования

- Текущий быстрый путь проверен прежде всего для полноразмерного непрозрачного Image-слоя в режиме Normal с opacity 100%. Для частично прозрачных PNG, других blend modes и opacity ниже 100% редактор использует более осторожный и более дорогой путь композиции.
- Sparse tiles пока накладываются поверх исходного raster. Полная replacement-семантика тайла, при которой прозрачный записанный пиксель способен стереть исходный raster-пиксель без повторного смешивания, ещё не реализована. Это отдельная P2-миграция формата слоя, истории и сериализации.
- Оптимизация 2026-08-21 убрала полные композиции для ограниченных мазков там, где это безопасно; она не означает, что все многослойные и прозрачные сценарии уже переведены на региональную композицию.

## Запуск

На Windows дважды нажмите `start-local.bat`. Скрипт устанавливает зависимости при первом запуске, собирает production и запускает `vite preview` на `http://127.0.0.1:4173`. Для разработки с HMR используйте `start-dev.bat` (`http://127.0.0.1:5173`). Оба окна остаются открытыми при ошибке.

Вручную:

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://127.0.0.1:5173`.

## Разработка и проверка

```bash
npm run typecheck
npm test
npm run build
```

Статичные effect previews пересобираются отдельно:

```bash
npm run generate:effect-previews
```

Исходные рендеры лежат в `public/assets/effect-previews/`, production-сборка создаётся в `dist/`.

Актуальные production-замеры post-stroke пути, baseline и известные оставшиеся full-canvas операции записаны в [`PERFORMANCE_REPORT_2026-08-21.md`](PERFORMANCE_REPORT_2026-08-21.md). Реализация, настройки, previews и Edge/Firefox acceptance экспериментальной пачки описаны в [`NEW_LAB_REPORT_2026-08-21.md`](NEW_LAB_REPORT_2026-08-21.md). Диагностика включается только параметром `?perf=1` и хранит ограниченное число последних измерений.

## Локальные данные

Документы и кисти не загружаются на сервер. Настройки и пользовательская Image Brush library хранятся в браузере. Очистка данных сайта удалит эту локальную библиотеку, поэтому важные исходники стоит хранить отдельно.
